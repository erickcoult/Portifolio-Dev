# English migration notes

This copy of the portfolio has been prepared for an English-speaking audience in New Zealand.

## Changed in the code

- Updated visible UI copy from Portuguese to natural English.
- Changed the document language to `en-NZ`.
- Changed the projects route from `/Projeto` to `/projects`.
- Added permanent redirects from the old Portuguese route to the new route.
- Renamed Portuguese component folders to English equivalents.
- Updated project metadata and page titles to English.
- Changed date formatting and experience durations to English/New Zealand formatting.
- Fixed several existing Tailwind/Framer Motion typos found during the translation pass.
- Removed the private study-notes file from this recruiter-ready copy.
- Kept the existing project slugs unchanged to avoid breaking individual project URLs.

## Hygraph

The source code still reads project descriptions, professional experience and the home introduction from Hygraph. Update the published Hygraph content using the accompanying `hygraph-content-en.json` / `HYGRAPH_ENGLISH_CONTENT.md` files before deploying if you want the live site to be fully English.
